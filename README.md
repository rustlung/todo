# To-Do List

Небольшое веб-приложение для управления задачами, выполненное как тестовое задание на позицию Vibe Coder.

Приложение позволяет создавать задачи, отмечать их выполненными, редактировать, удалять и фильтровать по статусу. Данные сохраняются в SQLite и не теряются после обновления страницы или перезапуска контейнера.

## Возможности

- добавление новых задач;
- редактирование существующих задач;
- отметка задачи выполненной и возврат в активное состояние;
- удаление с подтверждением;
- фильтры:
  - все;
  - активные;
  - выполненные;
- отображение количества активных задач;
- сохранение данных в SQLite;
- адаптивный интерфейс;
- валидация пользовательского ввода;
- автоматические тесты основных сценариев.

## Стек

- Python 3.12
- FastAPI
- Jinja2
- SQLAlchemy 2.x
- SQLite
- pytest
- Docker
- Docker Compose
- HTML / CSS / JavaScript

Зависимости и метаданные проекта описаны в `pyproject.toml`.

## Запуск через Docker

```bash
docker compose up --build -d
```

После запуска приложение будет доступно на порту, указанном в `docker-compose.yml`.

Проверить состояние контейнера:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f
```

Остановить приложение:

```bash
docker compose down
```

## Запуск тестов

```bash
docker compose exec web pytest
```

Если тесты запускаются локально вне Docker:

```bash
pytest
```

## Хранение данных

Для хранения задач используется SQLite.

Файл базы данных размещается в persistent volume / подключённой директории, поэтому данные сохраняются после пересоздания контейнера.
